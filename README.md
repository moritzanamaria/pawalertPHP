# PawAlert - Backend (PHP / Laravel)

Backend dio aplikacije **PawAlert** (sustav za prijavu i pronalaženje izgubljenih kućnih ljubimaca). 

Projekt je u početnoj fazi razvoja. Trenutno sadrži kopirane materijale iz prvotnog projekta koji će poslužiti kao podloga za izradu REST API-ja.

---

## 📌 Trenutni status
- Datoteke su skupljene na jedno mjesto radi lakšeg pregleda.
- Planira se čišćenje koda i prelazak na **Laravel** framework za izradu API-ja.
- Backend će služiti kao podrška za React + Vite frontend aplikaciju.

---

## 🛠️ Planirane tehnologije
* PHP (Laravel)
* MySQL
